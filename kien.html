조작

← ↑ ↓ → 또는 WASD방향 U I J KU = LP · I = RP · J = LK · K = RK 패드방향키·왼쪽 스틱, X=LP · Y=RP · A=LK · B=RK (Xbox 배치)

입력 요령

  1. → 는 톡 치고 바로 놓습니다. 놓는 순간이 중립(N)입니다.
  2. 키보드는 ↓ 를 누른 채로 → 와 I 를 동시에 누르면 ↘+RP 가 됩니다.
  3. 단축 커맨드는 → 를 놓은 뒤(N) 바로 ↘+RP 입니다. → 에서 놓지 않고 곧장 ↘ 로 가면 중립 누락으로 실패합니다.
  1. ↘+RP 로 기원권. 위쪽 큰 숫자가 지금 몇 프레임째인지 보여 줍니다.
  2. 회색 "경직"이 밝은 보라 "커맨드 구간"으로 바뀌는 47F에 →, 48F에 N(또는 ↓), 49F에 ↘+RP. 한 프레임이라도 비거나 밀리면 안 됩니다.
  3. 무족초(→ N ↘+RP)와 중립 생략(→ ↓ ↘+RP) 모두 인정합니다. 정식 →N↓↘ 는 4프레임이라 들어가지 않습니다.
  4. → 가 46F 이전에 끝나면 커맨드가 경직 중에 시작돼 기원권이 다시 나갑니다.

설정

단축 커맨드를 끄면 정식 커맨드(→N↓↘)만 성공으로 칩니다. 2P 쪽에서는 앞이 ← 입니다. 판정은 브라우저 시간 기준 60fps로 계산하며, 실제 게임의 입력 지연과는 차이가 있을 수 있습니다.
자동 기원권을 켜면 1~2초마다 기원권이 저절로 나가서 경직 이후 입력만 연습할 수 있습니다. 판정은 기원권을 입력한 프레임을 1F로 셉니다. 경직 1–46F, 초풍 히트 47–59F, 커맨드는 47F →, 48F N 또는 ↓, 49F ↘+RP 로 정확히 맞아야 성공입니다. 경직 중부터 → 를 누르고 있어도 47F에 → 상태면 인정합니다.
