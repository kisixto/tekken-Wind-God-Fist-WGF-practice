# tekken-Wind-God-Fist-WGF-practice — 철권 콤보 연습실

철권 카즈야의 초풍신권과 기원초 입력을 프레임 단위로 판정하는 브라우저 연습 도구입니다. 설치 없이 브라우저에서 동작하고, 연습마다 페이지가 나뉘어 있습니다. 위쪽 탭을 누르면 다른 연습 페이지로 이동합니다.

## 실행

`index.html`(초풍신권) 또는 `kien.html`(기원초)을 브라우저로 열면 바로 시작됩니다. GitHub Pages를 켜면(Settings → Pages → Branch: `main`) 링크로도 쓸 수 있습니다.

## 조작

- 방향: 방향키 또는 W A S D
- 버튼: U = LP, I = RP, J = LK, K = RK
- 패드: 방향키·왼쪽 스틱, X = LP, Y = RP, A = LK, B = RK (Xbox 배치)

## 초풍신권 (`index.html`)

| 커맨드 | 화살표 | 넘버패드 |
|---|---|---|
| 정식 | → N ↓ ↘ + RP | 6 N 2 3+RP |
| 철권 8 단축 | → N ↘ + RP | 6 N 3+RP |

↘가 들어간 첫 프레임에 RP가 같이 들어가야 초풍신권입니다. 늦으면 풍신권, 빠르면 "RP가 nF 빠름", 중립이나 ↓가 빠지면 그 원인을 알려 줍니다. 설정에서 단축 커맨드를 끄면 정식 커맨드만 성공으로 칩니다.

## 기원초 (`kien.html`)

기원권(↘+RP)을 입력한 프레임을 1F로 셉니다.

| 프레임 | 구간 | 넣을 입력 |
|---|---|---|
| 1–46F | 기원권 발생(14F 카운터)과 경직 | 없음 |
| 47F | 커맨드 구간 1 | → |
| 48F | 커맨드 구간 2 | N 또는 ↓ |
| 49F | 커맨드 구간 3 | ↘ + RP |
| 50–59F | 초풍 히트 구간 | 초풍 발동 11F, 59F에 히트 |
| 60F~ | 늦음 | 기원삑초 |

무족초(→ N ↘+RP)와 중립 생략(→ ↓ ↘+RP)을 세 프레임에 한 프레임씩 정확히 넣어야 성공이고, 한 프레임이라도 어긋나면 실패입니다. 프레임 막대에 구간과 실제 입력, 초풍이 맞은 프레임이 표시됩니다. "자동 기원권"을 켜면 기원권이 저절로 나가서 경직 이후 입력만 반복할 수 있습니다.

판정은 브라우저 시간을 60fps로 나눠 계산하므로 실제 게임의 입력 지연과는 차이가 있을 수 있습니다. 성공률과 기록은 브라우저에 저장됩니다.

## 파일

- `index.html`: 초풍신권 연습
- `kien.html`: 기원초 연습
- `tekken-ewgf-balance.xlsx`: 판정 기준(초풍 허용 지연, 기원초 경직·커맨드·히트 구간 계산), 커맨드와 판정 결과 표, 성공률로 보는 연습 목표 계산
