# tekken-Wind-God-Fist-WGF-practice — 초풍신권 연습

철권 카즈야의 초풍신권(초풍, EWGF) 입력을 프레임 단위로 판정하는 브라우저 연습 도구입니다. 설치 없이 `index.html` 하나로 동작합니다.

## 실행

`index.html`을 브라우저로 열면 바로 시작됩니다. GitHub Pages를 켜면(Settings → Pages → Branch: `main`) 링크로도 쓸 수 있습니다.

## 커맨드

| 커맨드 | 화살표 | 넘패드 |
|---|---|---|
| 정식 | → N ↓ ↘ + 2 | 6 5 2 3+2 |
| 철권 8 단축 | → N ↘ + 2 | 6 5 3+2 |

↘ 가 들어간 첫 프레임에 2가 같이 들어가야 초풍신권입니다. 설정에서 단축 커맨드를 끄면 정식 커맨드만 성공으로 칩니다.

## 조작

- 방향: 방향키 또는 W A S D
- 버튼: U = 1 (LP), I = 2 (RP), J = 3 (LK), K = 4 (RK)
- 패드: 방향키·왼쪽 스틱, X = 1, Y = 2, A = 3, B = 4 (Xbox 배치)

## 판정

- **초풍신권**: ↘ 와 2가 같은 프레임
- **풍신권**: 2가 1F 이상 늦음
- **2가 nF 빠름**: ↘ 전에 2가 먼저 들어감
- **중립(N) 누락**: → 를 놓지 않고 바로 아래나 대각으로 감
- **↓ 누락**: 단축 커맨드를 끈 상태에서 → N ↘ 입력
- **→ 누락**, **↘ 미완성**

마지막 시도는 프레임 타임라인으로, 모든 입력은 오른쪽 입력 기록에 표시됩니다. 성공률과 연속 기록은 브라우저에 저장됩니다.

판정은 브라우저 시간을 60fps로 나눠 계산하므로 실제 게임의 입력 지연과는 차이가 있을 수 있습니다.

## 파일

- `index.html`: 연습 도구
- `tekken-ewgf-balance.xlsx`: 판정 기준(프레임레이트, 허용 지연, 대기 프레임), 커맨드와 판정 결과 표, 성공률로 보는 연습 목표 계산
